# DSA Gemini Chatbot

A beginner‑friendly Data Structures & Algorithms chatbot built using
Google Gemini LLM and Next.js.

## Tech Stack
- Google Gemini LLM (gemini‑1.5‑flash)
- Next.js (Frontend + Backend)
- React
- JavaScript
- HTML & CSS

## Setup Instructions
1. Clone the repository
2. Run `npm install`
3. Create a `.env.local` file
4. Add your Gemini API key:

GEMINI_API_KEY=your_api_key_here

5. Run `npm run dev`

## Note
To run this project, generate your own API key from Google AI Studio and
paste it into the environment variable.
